# Ucam – AI-Powered Surveillance System 👁️🎯

### 🚀 Project by Team Seekers – Code for Bharat Season 2.0

Welcome to **Ucam**, a smart surveillance solution developed as part of **Code for Bharat Season 2.0**. This project reflects our **2 months of focused effort**, innovation, and teamwork to create a robust and intelligent camera-based monitoring system for public safety and disaster response.

---

## 🔍 About the Project

**Ucam** (short for *"Survive @ Cam"*) is an AI-driven real-time surveillance application that leverages modern technologies to:

- Detect suspicious activities or human presence using OpenCV and machine learning.
- Send real-time alerts and email notifications using Nodemailer.
- Store and manage logs using MongoDB.
- Provide a lightweight web interface for live monitoring and report generation.

> The system is built to assist **urban surveillance**, **disaster monitoring**, and **public safety response** using minimal hardware and software setup.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **AI & Detection:** Python + OpenCV
- **Database:** MongoDB
- **Communication:** Nodemailer for email alerts
- **Deployment:** Localhost / Cloud (Planned for Render / Railway)
